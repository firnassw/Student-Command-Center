# Student Command Center

Personal academic management PWA untuk mahasiswa — mengelola jadwal kuliah,
absensi, catatan pertemuan, materi, tugas, dan project dalam satu tempat.

## Status
Phase 3 — Vertical Slice #1 (Auth → Course → Schedule → Dashboard)

## Tech Stack
- Frontend: React + Vite
- Backend: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- Styling: CSS / Tailwind CSS
- Deployment: Netlify (rencana)
